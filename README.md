
# 🦟 DengueData 🦟

## Sobre o projeto

O DengueData é uma proposta de plataforma digital para visualização e análise de dados públicos relacionados à dengue no Brasil.

O projeto está sendo desenvolvido como parte do FMU TECH Inovação 2026, relacionado ao Objetivo de Desenvolvimento Sustentável (ODS) 3 — Saúde e Bem-Estar.

## Objetivo

Facilitar a compreensão de informações epidemiológicas sobre dengue por meio de gráficos, indicadores e visualizações de dados públicos.

## Público-alvo

- População em geral
- Estudantes
- Pesquisadores
- Pessoas interessadas em dados de saúde pública

## Tecnologias previstas

- HTML

## Fonte de dados

Ministério da Saúde — Dados públicos epidemiológicos.
