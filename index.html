Sobre o projeto

O DengueData é um dashboard desenvolvido para visualizar registros epidemiológicos de dengue, facilitando a compreensão da distribuição dos dados ao longo do tempo e entre estados brasileiros.

Os indicadores são utilizados para fins de visualização e análise exploratória dos dados disponíveis.

Metodologia e limitações

O dashboard utiliza registros do arquivo CSV do SINAN referente ao ano de 2026.

Os registros contabilizados não representam necessariamente casos confirmados ou totais epidemiológicos consolidados. Os dados podem estar sujeitos a atualização, revisão, duplicidade e inconsistências.

A identificação de óbitos utiliza um critério preliminar baseado no campo de evolução do registro, não sendo considerada uma contagem oficial consolidada.

A média mensal é calculada com base nos meses que possuem registros no conjunto de dados processado.
